Built a machine learning model to predict employee salaries based on experience, education, and job role.
Performed data cleaning, exploratory data analysis, and regression modeling to identify key salary drivers.

## 🔍 Key Insights

* Certain job roles show significantly higher salary ranges
* Education level contributes but is less influential than experience

# Salary Prediction Project

## Overview

This project predicts employee salaries using machine learning based on features like experience, education, and role.

## Problem Statement

Companies need a data-driven approach to determine fair salary ranges. This project helps in predicting salaries based on historical data.

## Approach

* Data Cleaning & Preprocessing
* Exploratory Data Analysis (EDA)
* Feature Engineering
* Model Building using Regression

## Tools & Technologies

Python, Pandas, NumPy, Scikit-learn, Matplotlib

## Results

* Built a regression model to predict salaries
* Identified key factors influencing salary

## Business Impact

* Supports HR teams in salary benchmarking
* Helps in making fair and consistent compensation decisions
